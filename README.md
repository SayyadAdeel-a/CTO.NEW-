# No-Code CV/Resume Builder

A one-click CV/Resume Builder with multiple implementation options: working web application and no-code platform blueprints.

## 🚀 Quick Start

### Option 1: Use the Web Application (Code-based)
1. Open `index.html` in a web browser
2. Fill in your information
3. Preview and download your CV as PDF

### Option 2: Build with No-Code Tools
Follow the detailed guides in the `no-code-guides/` directory:
- **Glide**: Mobile-first app builder
- **Bubble**: Full-featured web app platform
- **Softr**: Quick website builder with Airtable integration

## ✨ Features

- ✅ User-friendly form for CV data entry
- ✅ Real-time CV preview
- ✅ Professional, minimalist design
- ✅ Mobile-responsive layout
- ✅ PDF download functionality
- ✅ Multiple sections: Personal Info, Education, Work Experience, Skills
- ✅ Optional social links (LinkedIn, Portfolio, GitHub)

## 🛠️ Technology Stack

### Code-based Implementation
- HTML5, CSS3, JavaScript
- jsPDF library for PDF generation
- Responsive design with CSS Grid/Flexbox

### No-Code Platforms
- **Glide**: For mobile apps
- **Bubble**: For web applications
- **Softr**: For quick websites with Airtable
